# LoL Team Manager (Custom Game Helper)

LoL 클라이언트의 사용자 설정 게임 로비에서 멤버를 불러오고,
버튼 한 번으로 랜덤 팀 섞기를 지원합니다.

## 실행 방법 (일반 사용자)

1. [Releases](https://github.com/Nyppp/lol-web/releases) 페이지에서 최신 버전의 `lol-web.exe` 다운로드
2. 더블 클릭 실행
3. 자동으로 브라우저가 열리며, `http://127.0.0.1:5000/` 에서 사용 가능

⚠️ 반드시 **LoL 클라이언트가 켜져 있어야 합니다!**

## API Endpoints

Flask 서버가 켜지면 `http://127.0.0.1:5000` 기준으로 아래 엔드포인트가 제공됩니다.

### 1. `/` (GET)
- 메인 화면 (index.html 렌더링)
- 버튼 UI에서 멤버 불러오기 / 팀 섞기 기능 제공

### 2. `/fetch` (GET)
- 현재 LoL 클라이언트의 커스텀 게임 로비 멤버를 불러옵니다
- 응답(JSON):
```json
{
  "team100": ["플레이어1", "플레이어2"],
  "team200": ["플레이어3", "플레이어4"]
}
```

### 3. /shuffle (GET)
- 현재 로비 멤버들을 랜덤으로 섞어 팀을 재배치합니다
- 응답(JSON):
```json
{
  "team100": ["플레이어3", "플레이어1"],
  "team200": ["플레이어2", "플레이어4"]
}
```
