# LoL Team Manager (Custom Game Helper)

LoL 클라이언트의 사용자 설정 게임 로비에서 멤버를 불러오고,
버튼 한 번으로 랜덤 팀 섞기를 지원합니다.

## 실행 방법 (일반 사용자)

1. [Releases](https://github.com/Nyppp/lol-web/releases) 페이지에서 최신 버전의 `lol-web.exe` 다운로드
2. 더블 클릭 실행
3. 자동으로 브라우저가 열리며, `http://127.0.0.1:5000/` 에서 사용 가능

⚠️ 반드시 **LoL 클라이언트가 켜져 있어야 합니다!**
